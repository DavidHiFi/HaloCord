# Contributing to MochaCord

Thanks for helping. Bug reports, ideas and pull requests are all welcome.

## Reporting a bug

[Open an issue](https://github.com/DavidHiFi/MochaCord-Client/issues/new) and include:

- what you did, what you expected and what happened instead
- your Windows version and the release version you run
- a screenshot if the problem is visual

## Suggesting a feature

Open an issue that describes what you want and why. A mock-up helps.

## Sending a pull request

1. Fork the repo and create a branch from `main`.
2. This repository carries the client description, the update manifest and the release
   downloads. The client ships as Windows binaries, so most fixes land in a new release
   rather than in this repo.
3. Keep each pull request to one change, and say in the description how you tested it.

Theme work with the same name belongs in
[DavidHiFi/MochaCord](https://github.com/DavidHiFi/MochaCord).
