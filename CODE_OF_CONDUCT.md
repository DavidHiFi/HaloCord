# Code of conduct

Be kind in issues, pull requests and anywhere else this project lives.

- Treat everyone with respect, whatever their skill level.
- Keep feedback about the work, not the person.
- No harassment, slurs, spam or trolling.

The maintainer may edit or remove comments, close threads, and block anyone who breaks these rules.
To report a problem, [open an issue](https://github.com/DavidHiFi/HaloCord/issues/new) or contact [DavidHiFi](https://github.com/DavidHiFi) on GitHub.
